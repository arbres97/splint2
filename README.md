# Splint — VST3 для Ableton Live (Windows)

Чоп-ресемплер для вокала. Этот репозиторий собирает сам себя на серверах GitHub,
ничего устанавливать на свой компьютер не нужно. Писать код тоже не нужно.

## Как получить готовый плагин

1. Заведи бесплатный аккаунт на **github.com**, если его нет.
2. Нажми **New repository**, имя любое, например `splint`, тип **Public**, кнопка **Create repository**.
3. На странице пустого репозитория нажми **uploading an existing file**.
4. Распакуй архив, который тебе дали, и перетащи в окно браузера **всё содержимое папки**:
   `CMakeLists.txt`, `README.md`, папки `Source`, `tests` и `.github`.
   Важно: перетаскивать надо сами файлы и папки, а не папку `splint-plugin` целиком.
5. Внизу нажми зелёную кнопку **Commit changes**.
6. Перейди на вкладку **Actions**. Там появится запуск «Собрать Splint для Windows».
   Если GitHub спросит разрешение на запуск, нажми **I understand my workflows, go ahead and enable them**.
7. Подожди примерно 5–10 минут, пока рядом с запуском не появится зелёная галочка.
8. Открой этот запуск, внизу в разделе **Artifacts** скачай **Splint-VST3-Windows**.

Если вместо галочки появился красный крестик, открой запуск, скопируй текст ошибки
и пришли его мне, я поправлю.

## Куда положить плагин

1. Распакуй скачанный архив. Внутри будет папка **Splint.vst3** (именно папка, так устроен формат VST3).
2. Скопируй её целиком в:
   `C:\Program Files\Common Files\VST3\`
3. Запусти Ableton Live: **Options → Preferences → Plug-Ins**.
   Включи **Use VST3 Plug-In System Folders**, нажми **Rescan**.
4. В браузере Live: **Plug-Ins → Splint**. Перетащи его на **MIDI-дорожку**: это инструмент, а не эффект.

## Как играть

- Нажми **Play** в Live: плагин идёт по транспорту проекта, темп берёт из Live.
  Если хочется слышать его без запуска транспорта, включи галочку **Играть без транспорта**.
- **Загрузить семпл** — свой вокал (WAV, AIFF, MP3, FLAC, OGG). Пока не загрузил — играет встроенный демо-вокал.
- **Нарезка**: «Фразы» режет по паузам между словами, «Атаки» по транзиентам, «Сетка» ровно.
- **Стиль** и **Сгенерировать A и B** собирают два паттерна, **Морф A-B** переключает между ними по долям.
- Стиль **«Фигуры и филлы»** раскладывает ровные повторяющиеся фигуры, они же используются
  кнопками **Фигуру в A / в B**, **Филл, пока держишь** и **Авто-филл**.
- **Деконструкция**: восемь пэдов. Клик включает или выключает модуль, «Хаос» масштабирует их силу.
- **MIDI**: ноты C1–G#1 (36–43) держат пэды 1–8, нота A1 (44) держит филл.
  То есть модулями можно играть с клавиатуры или контроллера и записывать это в Live как MIDI.
- Все ручки — обычные параметры плагина, их можно автоматизировать и мапить на контроллер.

## Если захочется пересобрать после правок

Любое изменение файлов в репозитории снова запускает сборку на вкладке Actions.
